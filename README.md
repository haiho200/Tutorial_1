# Tutorial_1 · Beginner Python

Interactive CPE 1001L Python tutorial in the Sense HAT simulator.

Open the GitHub Pages site to start the guided tutorial. Students do not need a Python installation or GitHub account.

Eight lessons cover printing, variables and data types, arithmetic, comparisons, text input, integer input, receipts, and a final snack-shop exercise. Each lesson combines a coding exercise with an understanding question. Both must pass before the lesson appears in **Lessons Successfully Completed**.

For an assignment covering lessons 1–3, submit a screenshot showing **Lessons Successfully Completed: 1, 2, 3**.

Progress survives refreshes in the same browser tab. Use **Save progress** before closing the tab; **Open progress** restores that file. **Save .py** saves the current Python program. The final lesson also offers a written learning record. Progress and output checks are learning aids, not secure grading.

The Python runtime is bundled locally. Its original license is in `PYODIDE-LICENSE.txt`. Files are kept at the repository root so GitHub Pages can serve this app without a build step. The optional playground is available through **Return to playground**.
